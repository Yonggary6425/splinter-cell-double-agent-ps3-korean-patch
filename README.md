# 스플린터 셀: 더블 에이전트 (PS3) 한글패치

PS3 「Tom Clancy's Splinter Cell: Double Agent」 북미판(BLUS30032)의 비공식 한글패치입니다.
메뉴·HUD·문서 등 게임 텍스트를 한국어로 옮겼고, 원본에 자막이 없던 실시간 컷신과 음성 대사에도 한글 자막을 넣었습니다.

- 제작: 용가리 ([@Yonggary6425](https://github.com/Yonggary6425))
- 최신 버전: **v1.0**
- 다운로드: [Releases](../../releases)

## 대상 게임

| 항목 | 내용 |
|---|---|
| 제목 | Tom Clancy's Splinter Cell: Double Agent (북미판) |
| 제품 코드 | BLUS30032 |
| 게임 버전 | 02.02 |
| 형태 | 복호화(decrypted)된 ISO, 또는 폴더로 풀어 둔 게임 |

유럽판(BLES), 일본판, 암호화된 ISO에는 적용되지 않습니다.
**이 저장소와 패치에는 게임 파일이 들어 있지 않습니다.** 본인이 가진 게임에 적용해서 사용하세요.

## 주요 기능

- 메뉴, HUD, 장비 설명, 문서, 임무 목표, 로딩 화면, 신뢰도 이벤트 등 텍스트 전체 한글화
- 본고딕(Noto Sans KR) 기반 한글 글꼴
- 게임 중 대사 자막 (좌측 하단 알림창, 긴 대사는 나눠서 차례로 표시)
- 실시간(엔진) 컷신 대사 자막 — 원본에 자막 원문이 없어 음성을 받아쓰고 번역해 추가
- 경비병 혼잣말, 교전 외침, 임무 실패 대사, 훈련 테스트 내레이션 등 음성 대사 약 2,250개 자막

## 적용 방법 (ISO)

1. [Releases](../../releases)에서 `SCDA_KOR_v1.0.zip`을 받아 압축을 풉니다.
2. `ISO_적용.bat` 위에 원본 ISO를 끌어다 놓습니다.
3. 처음 실행하면 「준비 필요」 안내가 나옵니다(정상).
   - 패처가 ISO에서 `sc4_offline.self`를 꺼내 패치 폴더에 저장합니다.
   - Enter를 눌러 창을 닫습니다. (Y를 누르면 자막 없이 텍스트만 한글화)
   - RPCS3 → 유틸리티(Utilities) → PS3 바이너리 복호화(Decrypt PS3 Binaries)에서
     그 파일을 고르면 같은 폴더에 `sc4_offline.elf`가 생깁니다.
4. `ISO_적용.bat`에 원본 ISO를 다시 끌어다 놓고 적용 방식을 고릅니다.
   - [1] 새 ISO로 저장 (권장): 원본은 그대로 두고 `… (KOR).iso`를 새로 만듭니다.
   - [2] 원본 ISO에 바로 적용
5. 「완료!」가 나오면 끝입니다.

> `sc4_offline.elf`는 한 번 만들어 두면 계속 쓸 수 있습니다. 패치 폴더나 ISO와 같은 폴더에 두면 3번 과정 없이 바로 적용됩니다.
> 반드시 **패치하지 않은 원본 ISO**에 적용하세요.

## 적용 방법 (폴더로 풀어 둔 게임)

1. 압축을 푼 `SCDA_KOR_v1.0` 폴더를 게임 폴더(`PS3_GAME`이 있는 곳) 안에 넣습니다.
2. `PS3_GAME\USRDIR\offline\sc4_offline.self`를 RPCS3로 복호화해 같은 폴더에 `sc4_offline.elf`를 만듭니다.
3. `폴더_적용.bat`을 실행합니다. 원본은 같은 위치에 `.orig`로 백업됩니다.

## 주의

- 콘솔(또는 RPCS3)의 시스템 언어는 **영어(English)** 로 두세요.
- 실행 파일은 fake-signed(fself)입니다. 실기에서는 CFW/HEN 환경이 필요합니다.
- 실행할 때 「Windows의 PC 보호」 창이 뜨면 [추가 정보] → [실행]을 누르세요.

## 알려진 제한

- 비명·콧노래 등 말이 아닌 소리에는 자막이 없습니다.
- 같은 상황에서 서로 다른 대사가 무작위로 나오는 일부 외침에는 자막이 없습니다.
- 음성을 받아써 번역한 대사는 실제 음성과 조금 다를 수 있습니다.
- 미리 녹화된 동영상(.bik) 컷신에는 자막이 없습니다.

## 패치 방식

- 게임 데이터(`.lin`)는 원본과 달라진 부분만 담은 차분 파일(`.kpt`)로 배포하며, 사용자의 원본 파일에서 패치된 파일을 다시 만듭니다.
- 실행 파일은 원본 복호화본(`sc4_offline.elf`)에 대한 차분(`.kpe`)만 담고 있습니다.
- ISO 패처는 ISO9660 디렉터리 정보를 직접 고쳐 바뀐 파일을 교체하며, 소스(`tools/IsoPatch.cs`)를 함께 공개합니다.
